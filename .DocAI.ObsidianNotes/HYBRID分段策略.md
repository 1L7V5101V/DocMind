HYBRID 是**两层嵌套分段**：先按章节粗分，再对每个章节内部做语义细粒度切分。

```
原始文档
  ↓ CHAPTER 分段
章节1               章节2               章节3
  ↓                  ↓                  ↓
SEMANTIC分段        SEMANTIC分段        SEMANTIC分段
  ├─ 片段1.1          ├─ 片段2.1          ├─ 片段3.1
  ├─ 片段1.2          ├─ 片段2.2          └─ 片段3.2
  └─ 片段1.3          └─ 片段2.3
```

具体流程（`segmentWithHybrid()`，`DocumentSegmenter.java:75`）：

1. **CHAPTER** → 先按章节结构把整篇文档切分成大块
2. **遍历每个章节** → 对每个章节的内容单独调用 `SEMANTIC` 策略（语义相似度聚类，目标长度 300，最小 100，阈值 75）
3. **标题继承** → 如果语义分段后的片段没有自己的标题，继承父章节的标题
4. **去重** → 对所有片段做归一化去重（忽略大小写和空白），防止相邻片段内容重复
5. **重编号** → 统一生成 `documentId_hybrid_0`, `_hybrid_1`... 的 ID

**效果：** 既保留了章节的结构信息（标题），又解决了单个章节过长时需要进一步拆分的问题。
