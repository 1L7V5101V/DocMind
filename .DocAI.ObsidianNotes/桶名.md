**桶（Bucket）是对象存储中的顶层命名空间**，类似于文件系统的"根目录"或操作系统的"磁盘分区"。

在 MinIO / AWS S3 这类对象存储中：
- **桶**是存储对象的容器，所有文件（对象）都必须放在某个桶里
- **桶名**是这个容器的唯一标识，全局唯一（整个 MinIO 集群中不能重名）
- 访问一个文件时路径是：`桶名/对象键`，例如 `doc-ai/users/avatar.jpg`

类比关系：

| 概念   | 传统文件系统                | 对象存储（MinIO/S3）                        |
| ---- | --------------------- | ------------------------------------- |
| 顶层容器 | 磁盘分区（C:、D:）           | **桶（Bucket）**                         |
| 文件标识 | `C:\path\to\file.txt` | **桶名/对象键**（`doc-ai/path/to/file.txt`） |
| 权限控制 | 目录权限                  | 桶策略（Bucket Policy）                    |

在项目中的作用：
- **按用户隔离** — 每人一个桶（`user-u123`），防止 A 用户看到 B 用户的文件
- **权限控制** — 配置 `bucket-permissions` 指定哪些角色能访问哪些桶
- **逻辑分组** — `doc-ai` 放通用文件，`document` 放文档内容，职责分离
