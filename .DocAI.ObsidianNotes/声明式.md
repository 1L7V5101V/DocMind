**声明式** = 你**声明"要什么"**，不写"怎么干"。

对比理解：

| | 声明式 | 命令式 |
|--|--------|--------|
| 做法 | 定义接口和方法签名 | 手动构造 HTTP 请求、解析响应 |
| 代码 | `interface UserClient { User getById(Long id); }` | `HttpClient.get("http://host:port/user/1").parse(User.class)` |
| 关注点 | **做什么** | **怎么做**（拼接 URL、序列化、重试……） |

OpenFeign 的"声明式"就是：你写个 Java 接口，框架自动在背后替你生成 HTTP 客户端代码——你只声明 API 契约，底层的网络通信、负载均衡、重试全由框架包办。
