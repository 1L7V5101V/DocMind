**本地[^1]启发式重排**（`computeLocalCrossEncoder()`, line 290）怎么做：

```java
private float computeLocalCrossEncoder(String query, String document) {
    // 1. 关键词匹配比例
    for (每个查询词) {
        if (文档包含这个词) matchCount++
    }
    baseScore = matchCount / 总词数

    // 2. 位置权重（关键词出现在文档开头，加分）
    for (每个查询词) {
        if (出现在文档前1/3处) positionBonus += 0.1f
    }

    return clamp(baseScore + positionBonus)
}
```

就是简单的**关键词命中率 + 位置加分**——虽然不如远程 rerank 模型精准，但保证检索链路不会因为外部服务挂了就整个断掉。`rerankEnabled` 为 `false` 或 API 调用抛异常时都会走这个降级路径。

[^1]: **启发式（heuristic）** 在计算机里 = **"凭经验凑合的解法，不保证最优，但够用"**，和精确算法相对。

	| | 精确算法 | 启发式 |
	|---|---|---|
	| **远程 Cross-Encoder** | 用深度神经网络算 query 和文档的相关性，理论上限高 | — |
	| **本地降级** | — | 简单算关键词命中率+位置加分，`O(1)` 搞定，不求最优，只求"别让检索链断掉" |
	
	之所以叫启发式，是因为它基于两个**经验规则**（heuristic rules）：
	1. **关键词命中越多越相关** — 大多数时候成立，但不保证（可能关键词堆砌但实际不相关）
	2. **关键词出现在文档开头更重要** — 常见于文档结构，但不绝对
	
	没有用模型，没有训练，就是几条人类经验写死的 if-else，所以叫**启发式降级**——不漂亮，但能兜底。
