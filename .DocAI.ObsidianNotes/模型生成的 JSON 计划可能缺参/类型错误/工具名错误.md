**三层兜底：

**第一层：规划规范（normalizePlan）**

模型返回 JSON 计划后，不管写的什么，服务端重新洗一遍：

```java
// 工具名不存在→直接降级为 direct-answer
if (!toolRegistry.contains(step.getToolName())) {
    step.setToolName("direct-answer");
}
// 没写 ID → 自动编号
if (isBlank(step.getId())) { step.setId("step-" + index); }
// 没写描述 → 用用户任务补
if (isBlank(step.getDescription())) { step.setDescription(request.getTask()); }
// 没写风险等级 → 从注册表查
// 危险操作 → 自动标记需审批
// 没写重试策略 → 非危险用 exponential，危险用 none
```

**第二层：模型规划失败，规则代替（fallbackPlan）**

如果模型根本输出不了 JSON（报异常），服务端不用模型了，自己按关键词硬编码规划：

```java
// 规则举例：
if (包含"总结""分析"等词)        → tool = "rag-answer"  
if (包含"删除"且有 documentId)   → tool = "file-delete"
if (包含"生成""PPT")             → tool = "html-ppt-generate"
if (都不匹配)                     → tool = "direct-answer"（直接问用户）
```

**第三层：执行前参数校验（validateToolParameters）**

执行每个工具前，对照注册表的参数 schema 逐项检查：

```java
if (必填参数缺失)    → 返回 actionRequired，问用户补齐
if (类型不对)        → 返回 actionRequired，"期望 integer，实际是 string"
if (超过最大值)      → 返回 actionRequired，"topK 最大 50"
if (不在允许值列表)  → 返回 actionRequired，"仅允许: bm25, cross_encoder"
```

**效果：** 模型写错工具名 → 降级为 direct-answer（不会报 500）；模型缺参 → 卡住问用户（不会用 null 去调文件删除接口）；[^1]模型给字符串当数字 → 校验拦截（不会传到业务层抛类型转换异常）。**业务层的 Service 永远只收到经过校验的合法参数。****

[^1]: 一个具体例子：
	
	模型给 JSON 计划里写：
	
	```json
	{
	  "toolName": "rag-search",
	  "params": {
	    "query": "季度报告",
	    "topK": "五十"    ← 模型给了中文字符串，但 topK 应该是数字
	  }
	}
	```
	
	服务端执行前，`validateToolParameters` 先查注册表里 `rag-search` 的 `topK` 参数 schema——类型是 `integer`。
	
	然后走到 `isTypeCompatible("五十", "integer")`：
	
	```java
	// "五十" instanceof Number → false
	// "五十".matches("^-?\\d+$") → false
	return false;
	```
	
	返回 false → 不往下执行 `ragSearchService.search(...)` → 返回 `actionRequired`：
	
	```json
	{
	  "status": "actionRequired",
	  "message": "工具 rag-search 缺少必要信息: 非法参数 [topK]",
	  "data": {
	    "toolName": "rag-search",
	    "invalidParameters": { "topK": "期望类型: integer" },
	    "nextStep": "请补齐缺失或类型不正确的参数后重试"
	  }
	}
	```
	
	**如果没有这个拦截：** `ragSearchService.search("季度报告", "五十")` → 底层可能强转 `Integer.parseInt("五十")` 抛异常 500，或者悄悄变成 0 返回错误结果。
