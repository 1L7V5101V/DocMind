这是文档中的**两层防护策略**：

```
                         ┌─────────────────┐
  请求 → 网关层（第一道） → 鉴权、白名单、日志   → 拦截非法请求
                         └─────────────────┘
                                     ↓ 放行
                         ┌──────────────────────┐
                         服务层（第二道）→ 权限校验       → 兜底保护
                         └──────────────────────┘
```

**网关层（第一道）**：
- `AuthGlobalFilter` 拦截所有请求
- 检查白名单路径（登录、注册、Swagger）
- 验证 Token 有效性
- 过滤掉明显的非法请求

**服务层（第二道）**：
- 各微服务继承 `BaseSecurityConfig`
- 配置具体的**接口级权限**（哪些接口需要 ADMIN 角色、哪些普通用户可访问）
- 即使请求绕过了网关（比如内部服务调用、测试环境直连），服务自身也能拦截

**为什么双层？**
- 网关挂了或被绕过 → 服务层还有保护
- 网关层只做通用鉴权，不关心具体业务权限 → 服务层做细粒度控制
- 两层各司其职，无盲区
