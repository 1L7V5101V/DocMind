| 维度        | LOCAL（本地开发）           | MINIO（[[生产分布式]]）    |
| --------- | --------------------- | ------------------- |
| **存储位置**  | 单机磁盘目录                | [[分布式对象存储]]集群       |
| **可靠性**   | 磁盘坏了数据丢               | 多副本/纠删码，坏几台不影响      |
| **扩展性**   | 受单机磁盘上限               | 加机器无限扩容             |
| **依赖**    | 零依赖，直接写文件             | 需要部署 MinIO 集群       |
| **跨服务访问** | 仅本机可读，A 服务不能读 B 服务的文件 | 各服务通过 HTTP API 统一访问 |
| **使用场景**  | 本地 debug、单元测试         | 正式上线多实例部署           |

**一句话：** LOCAL 是**开发时省事**，不用装额外服务；MINIO 是**生产环境可靠且可扩展**，微服务间也能统一存取文件。
