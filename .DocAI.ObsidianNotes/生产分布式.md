**生产** = 正式上线环境（区别于开发/测试）
**分布式** = 多台机器协同工作（区别于单机）

合在一起就是：**正式上线时，不再依赖单台机器的磁盘，而是多台机器组成集群来提供存储服务。**

### 为什么叫"分布式"？

传统单机模式（LOCAL）：

```
你部署了3个服务实例 → 文件存到各自机器的磁盘
用户上传 → 实例A 存了
用户下载 → 请求打到 实例B → 找不到文件 ❌
```

分布式存储（MinIO）：

```
你部署了3个服务实例 + 3台 MinIO 节点
用户上传 → 任何一个实例存到 MinIO 集群 → 数据自动分散到3台机器
用户下载 → 请求打到任何实例 → 从 MinIO 集群读取 → 找到文件 ✅
```

所以叫**分布式**，因为文件不是放在一台机器上，而是**分散在多台机器共同管理**，任何一个服务实例都能访问全部数据。
